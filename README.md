# Translate Offline

A simple macOS app for offline text translation using Apple's on-device translation framework.

### Features
- Offline translation
- Powered by Apple system model
- macOS native UI (SwiftUI)
- Free with 10 translations a day; a one-time Pro purchase removes the limit
                        
### Requirements
- macOS 26+
- On-device language models installed 


### In-app purchase
- Product: `iosipratama.TranslatorMac.pro` (non-consumable)
- Anyone whose original download is older than 1.2, the first free version, gets Pro automatically
- `Translate Offline.storekit` lets local runs buy Pro without App Store Connect
